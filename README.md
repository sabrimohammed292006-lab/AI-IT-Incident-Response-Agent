# 🤖 AI IT Incident Response Agent

An advanced, multi-agent AI system designed to automate IT incident classification, triage, investigation, and resolution workflows with built-in safety guardrails and human-in-the-loop review.

---

## 🚀 Features & Architecture

* **Automated Triage & Severity Assessment:** Categorizes incoming IT incidents by severity (Low, Medium, High, Critical) and routes them to appropriate workflows.
* **Intelligent Investigation:** Uses Retrieval-Augmented Generation (RAG) and local Knowledge Bases to diagnose root causes.
* **Safety & Guardrails:** Built-in validation layers to catch security risks, prompt injections, and unauthorized actions.
* **Human-in-the-Loop:** Automatically flags high-risk or security incidents for human review.
* **Gradio Web UI:** User-friendly interface for submitting incidents and viewing real-time agent responses.

---

## 🛠️ Tech Stack

* **Python** (Core Logic & Orchestration)
* **Gradio** (Web UI Interface)
* **LangChain / Custom Agents** (Workflow & Orchestration)
* **Pytest** (Automated Testing Suite)
